# Odin Essentials

Vidar is Odin plus a few features, so most of the code you'll write in Vidar is Odin. This chapter is a quick tour of the Odin that the rest of the book uses, and a list of what Vidar changes about it.

If you already write Odin, skip [the tour](ch02-01-odin-tour.md) and read [Coming from Odin](ch02-02-coming-from-odin.md). If you're new to Odin, read the tour now, and keep the [Odin overview](https://odin-lang.org/docs/overview/) at hand: it is the full description of the language, and it's short.
