# Shared Values with `vidar:rc`

One owner per value covers most programs. Sometimes, though, a value really is shared: several parts of a program hold on to it, and it should go away when the last of them lets go. `import "vidar:rc"` gives you `Rc(T)` for that: a counted owner of one `T` on the heap.

```vidar
# File :: struct { name: string }
# open :: proc(name: string) -> File { fmt.println("open", name); return File{name} }
# file_close :: proc(f: ^File) {
# 	if f.name == "" do return
# 	fmt.println("close", f.name)
# }
# impl Destroy for File { destroy = file_close }
#
import "vidar:rc"

main :: proc() {
	r := rc.new(open("shared"))       // rc.new takes the File over
	{
		s := r                        // a second owner: copies share the value
		fmt.println(rc.count(r))
		fmt.println(rc.get(s).name)   // get gives a ^File
	}                                 // s lets go here
	fmt.println(rc.count(r))
}                                     // r lets go: the File is closed and freed
```

<span class="caption">Listing 7-12: A file shared by two owners</span>

```output
open shared
2
shared
1
close shared
```

`Rc(T)` is built from the pieces of this chapter: it has `impl Clone`, whose clone adds one to the count, and `impl Destroy`, whose destroy takes one away and, at zero, destroys the value (with its own `impl Destroy`, if it has one) and frees the memory.

- `rc.new(value, allocator := context.allocator)` makes one, taking `value` over (it's an `#owned` parameter: pass a new value or `move!(x)`).
- `rc.get(r)` gives a `^T` to the shared value, which lives as long as some owner does.
- `rc.count(r)` is the number of owners. The zero `Rc` owns nothing and counts 0.
- Copies of an `Rc` are clones, so the last-use rule applies: a copy on an `Rc` local's last use moves it, without touching the count.

Counts are plain integers, and atomic only when the program is built with `-define:VIDAR_THREADS=N` for N above 1.

## Cycles and `Weak`

Two `Rc`s that own each other never reach zero, so they leak. Trees are the usual case: a parent owns its children, and a child wants to refer to its parent. Make one direction a `Weak(T)`, which refers to an `Rc`'s value without owning it:

```vidar
import "vidar:rc"

Node :: struct {
	name:     string,
	parent:   rc.Weak(Node),
	children: [dynamic]rc.Rc(Node),
}

main :: proc() {
	root := rc.new(Node{name = "root"})
	child := rc.new(Node{name = "leaf", parent = rc.downgrade(root)})
	append(&rc.get(root).children, move!(child))

	leaf := rc.get(root).children[0]
	up := rc.upgrade(rc.get(leaf).parent)        // an Rc again, while the parent lives
	fmt.println(rc.get(leaf).name, "->", rc.get(up).name)
	fmt.println(rc.count(root))
}
```

<span class="caption">Listing 7-13: A tree whose children point back with `Weak`</span>

```output
leaf -> root
2
```

- `rc.downgrade(r)` makes a `Weak` from an `Rc`.
- `rc.upgrade(w)` gives another `Rc` to the value, or the zero `Rc` once the value is gone.
- `rc.alive(w)` says whether the value still has an owner.

The memory is freed once the last `Rc` and the last `Weak` are both gone. The [`vidar:rc` reference](reference-06-rc.md) lists every procedure.
