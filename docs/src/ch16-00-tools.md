# Tools

This chapter covers the tools that come with Vidar:

- [The `vidar` Command](ch16-01-command-line.md): every command and flag, and standalone binaries.
- [Formatting with `vidar fmt`](ch16-02-fmt.md): a formatter that never moves a token to another line.
- [Editors and the Language Server](ch16-03-language-server.md): `vidar-lsp`, the VS Code extension, and setting up other editors.
- [Debugging](ch16-04-debugging.md): debug builds, `lldb` and `gdb`, and `vidar dap`, a debugger that works on `.vidar` lines.
