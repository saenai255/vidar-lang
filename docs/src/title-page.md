# The Vidar Programming Language

*by the Vidar contributors*

This book is about Vidar as it is on the `main` branch of [its repository](https://github.com/saenai255/vidar-lang), built with Odin `dev-2026-07`. Vidar is young: its version numbers count releases, not stability, and the language still changes from one release to the next. When this book and the compiler disagree, the compiler is right and the book has a bug; please [report it](https://github.com/saenai255/vidar-lang/issues).

Every program in this book is compiled by the test suite (`npm run test:docs`), and every one that shows its output is run and checked against it. The book's source is in [`docs/`](https://github.com/saenai255/vidar-lang/tree/main/docs).
